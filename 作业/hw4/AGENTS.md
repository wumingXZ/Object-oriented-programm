# AGENTS.md — HW4 学生成绩计算程序

> 本项目是面向对象程序设计课程的第四次作业（HW4），目录下包含一个未完成的 C++ 程序框架。所有核心逻辑均以 `//TODO` 占位，需要由开发者补充实现。

---

## 项目概览

本项目要求实现一个**基于类（class）**的学生成绩计算程序。

- **输入**：从标准输入读取多名学生的信息，每行格式为：
  ```
  姓名 期中成绩 期末成绩 作业1 作业2 ... 作业N
  ```
- **输出**：按学生姓名**字典序升序**输出每名学生的最终成绩：
  ```
  Name's final grade is X
  ```
- **成绩计算公式**：
  ```
  最终成绩 = 0.2 × 期中成绩 + 0.4 × 期末成绩 + 0.4 × 作业中位数
  ```
- **测试数据**：
  - 输入样例：`hw4_input.txt`
  - 期望输出：`hw4_output.txt`

> 作业原始要求见同目录下的 `hw4.txt`（GBK 编码）与 `面向对象程序设计202604-定义新类型_类.pdf`。

## 技术栈与架构

- **语言**：C++（标准库即可，无需第三方依赖）
- **构建工具**：无（无 Makefile、CMakeLists.txt 或 package.json 等配置文件）
- **运行架构**：单文件控制台程序，从 `stdin` 读取，向 `stdout` 输出
- **核心模块**：
  - `Student_info` — 学生信息类，封装姓名、成绩数据及输入操作
  - `grade` — 成绩计算函数（调用 median）
  - `median` — 计算一组数值的中位数

- **头文件保护宏**：现有文件使用 `GUARD_<filename>` 格式（如 `GUARD_Student_info`），新增头文件应保持一致风格。
- **命名空间**：现有代码在 `.cpp` 文件顶部使用了 `using namespace std;`，为保持风格一致性，补充代码可沿用此做法。
- **TODO 标记**：所有待实现的位置均以 `//TODO` 或 `// TODO` 标注，实现后应替换为实际代码。

## 测试策略

1. **基础测试**：使用提供的 `hw4_input.txt` 作为输入，验证输出与 `hw4_output.txt` 完全一致（包括排序和格式）。

3. **中位数计算验证**：`median` 函数需正确处理奇数个和偶数个元素的情况。
