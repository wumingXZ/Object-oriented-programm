## 〇、回顾第04周和第06周：你已经知道的

在第 04 周，你学会了写函数模板：
```cpp
template <typename T>
T median(vector<T> v) { ... }  // 一份代码，适用于所有类型
```

在第 06 周，你学会了写类模板：
```cpp
template <typename T>
```

这些是模板的"基础用法"。但在实际项目中（尤其是标准库的实现），模板远比这复杂。本文深入四个进阶主题：

## 一、模板参数推导

### 1.1 函数模板的实参推导

```cpp
// 模板参数推导：编译器从函数实参推断模板参数
template <typename T>
int compare(const T &a, const T &b) {
    if (a < b) return -1;
    if (b < a) return 1;
    return 0;
}

// T = int:  compare(1, 2)
// T = double:  compare(3.14, 2.72)

// 编译器只做有限的类型转换：
// - const 转换：非 const → const  ✅
// - 数组→指针、函数→指针         ✅
// - 其他隐式转换                  ❌

// compare(1, 2.0);  // ❌ 歧义！T 是 int 还是 double？
// 解决方案：显式指定模板参数
compare<double>(1, 2.0);
```

### 1.2 尾置返回类型和类型推导

```cpp
// C++11: 尾置返回类型 + decltype
template <typename T, typename U>
auto multiply(const T &t, const U &u) -> decltype(t * u) {
    return t * u;
}

// C++14: 返回类型自动推导（简化版）
template <typename T, typename U>
auto multiply14(const T &t, const U &u) {
    return t * u;
}

// 实际应用：返回容器元素
template <typename Container>
auto get_element(Container &c, size_t idx) -> decltype(c[idx]) {
    return c[idx];
}

multiply(3, 4.5);  // double

vector<string> v{"Hi", "Hello", "World"};
get_element(v, 1);
```

## 二、`typename` — 告诉编译器"这是个类型"

```cpp
// 当依赖模板参数的名字是类型时，必须用 typename 前缀
template <typename T>
void print_first(const T &container) {
    // ⚠️ 编译器不确定 T::const_iterator 是类型还是静态成员
    // 所以需要 typename 关键字
    typename T::const_iterator it = container.begin();

    if (it != container.end()) {
        // cout << *it
    }
}

vector<int> v{42, 1, 2, 3};
print_first(v);
```

> **规则：** 当一个依赖于模板参数的名字是类型时，必须用 `typename` 前缀。独立于模板参数的类型不需要（如 `int`、`string`）。

## 三、完美转发 `std::forward`

### 3.1 为什么需要 forward？

```cpp
// 左值版本
void process(const string &s) {
    // 左值引用版本
}

// 右值版本
void process(string &&s) {
    // 右值引用版本 (可移动!)
}

// ❌ 问题：forwarding 函数总是调用左值版本
template <typename T>
void bad_forward(T arg) {
    process(arg);  // arg 是左值（有名字！）→ 总是调用左值版本
}

// ✅ 完美转发：保持参数的"左值/右值"属性
template <typename T>
void good_forward(T &&arg) {
    process(forward<T>(arg));  // forward 保持 arg 的值类别
}

string s = "Hello";

bad_forward(s);                    // 左值版本 ✓
bad_forward(string("Temporary"));  // 应该右值版本 ✗

good_forward(s);                    // → 左值版本 ✓
good_forward(string("Temporary"));  // → 右值版本 ✓
```

### 3.2 万能引用 `T&&`

```cpp
// T&& 是"万能引用"（forwarding reference）——
// 可以绑定左值（T 推导为 T&，引用折叠为 T&）
// 也可以绑定右值（T 推导为 T，就是 T&&）
template <typename T>
void wrapper(T &&arg) {
    // forward<T>:
    //   - 如果 arg 是右值 → 转为右值（触发移动）
    //   - 如果 arg 是左值 → 保持左值（不移动）
}

string s = "left";
wrapper(s);                 // T = string&, 折叠后 arg 是 string&
wrapper(string("right"));   // T = string,  arg 是 string&&
wrapper(move(s));           // T = string,  arg 是 string&&
```

> **记忆诀窍：`T&&` + `forward<T>` = 完美转发。**
> - `move(x)` = 无条件转为右值
> - `forward<T>(x)` = 条件性转发（保持原值类别）

## 四、可变参数模板（Variadic Templates, C++11）

### 4.1 基本语法

```cpp
// 递归基：处理最后一个参数
template <typename T>
ostream &print(ostream &os, const T &t) {
    return os << t;  // 最后一个元素（不加分隔符）
}

// 可变参数模板：每次处理第一个参数，递归处理剩余
template <typename T, typename... Args>
ostream &print(ostream &os, const T &t, const Args&... rest) {
    os << t << ", ";                 // 输出第一个参数
    return print(os, rest...);       // 递归输出剩余参数
}

// 用法：print(cout, 42, 3.14, "Hello", string("World"))
//   → os << 42 << ", "  → print(cout, 3.14, "Hello", string("World"))
//     → os << 3.14 << ", "  → print(cout, "Hello", string("World"))
//       → os << "Hello" << ", "  → print(cout, string("World"))
//         → os << string("World")  ← 递归基
```

### 4.2 `sizeof...(Args)` — 参数数量

```cpp
template <typename... Args>
void count_args(Args... args) {
    sizeof...(Args);   // 参数数量
    sizeof...(args);   // 等价
}

count_args();            // 0
count_args(1);           // 1
count_args(1, 2.0);     // 2
count_args(1, 2.0, "hi"); // 3
```

### 4.3 `emplace_back` 原理揭秘

```cpp
// 简化版 vector::emplace_back 的实现原理
class MyVector {
public:
    // 可变参数 + 完美转发 = emplace_back 的核心
    template <typename... Args>
    void emplace_back(Args&&... args) {
        // 实际实现中：new (ptr) T(forward<Args>(args)...);
    }
};

MyVector v;

v.emplace_back();                        // 0 个参数 → 默认构造
v.emplace_back(42);                      // 1 个参数
v.emplace_back("hello", 5);              // 2 个参数
v.emplace_back(string("world"));         // 1 个参数（string&&）

// 对照：vector<string> 的 emplace_back
vector<string> vs;
vs.emplace_back(10, 'c');     // 直接在容器内构造 string(10, 'c')
```

## 五、模板特化（Specialization）

```cpp
// 通用模板
template <typename T>
int compare(const T &a, const T &b) {
    if (a < b) return -1;
    if (b < a) return 1;
    return 0;
}

// 全特化：针对 const char * 的特殊处理
template <>
int compare(const char* const &a, const char* const &b) {
    return strcmp(a, b);
}

compare(1, 2);  // 调用通用模板

const char *s1 = "apple";
const char *s2 = "banana";
compare(s1, s2);  // 调用特化版本
```

## 六、类模板的成员模板

```cpp
// 简化版 unique_ptr（演示成员模板）
template <typename T>
class SimplePtr {
    T *ptr_;
public:
    explicit SimplePtr(T *p = nullptr) : ptr_(p) {}

    // 成员模板：允许从 D* 转换到 T*（如派生类 → 基类）
    template <typename D>
    explicit SimplePtr(D *p) : ptr_(p) {}  // 注意：实际实现需要更谨慎

    T *get() const { return ptr_; }
    ~SimplePtr() { delete ptr_; }
};

struct Base { virtual ~Base() = default; };
struct Derived : Base {};

SimplePtr<Base> p(new Derived);  // 通过成员模板：派生类指针 → 基类智能指针
```

### 模板知识体系

```
模板基础（第04/06周）

模板进阶（本文）

├── 万能引用 & 完美转发
│   ├── T&& + forward<T>
│   └── move vs forward 的区别

│   └── emplace_back 原理
└── 模板特化
    ├── 全特化 template<>
    └── 偏特化（类模板）
```

### 核心原则

| 技巧 | 用法 |
|---|---|
| 推导失败 | 显式指定模板参数 `f<int>(x)` |
| `typename` | 标记依赖模板参数的类型名 |
| `forward<T>` | 保持参数的值类别（完美转发） |
| `move` | 无条件转为右值 |
| `T&&` + `forward` | 万能引用 + 完美转发 = emplace 核心 |
| `Args...` | 可变参数——递归展开处理 |
