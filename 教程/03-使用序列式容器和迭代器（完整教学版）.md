## 〇、C 语言回顾：我们以前是怎么管理数据的？

学过 C 语言的同学一定记得：

```c
// C 语言方式：固定大小数组，手动管理
#define MAX_STUDENTS 100
struct Student {
    char name[50];
    int scores[10];
    int score_count;
};
struct Student class_roster[MAX_STUDENTS];  // 预分配100个位置
int student_count = 0;

// 添加学生时：
strcpy(class_roster[student_count].name, "Alice");
class_roster[student_count].scores[0] = 95;
class_roster[student_count].score_count = 1;
student_count++;

// 删除中间的学生？（需要手动移动后面所有元素！）
for (int i = index; i < student_count - 1; i++) {
    class_roster[i] = class_roster[i+1];  // 逐元素复制
}
student_count--;
```

C 语言方式的问题：
- **固定大小**：数组要么太大浪费空间，要么太小不够用
- **手动管理**：插入删除要自己写循环移动元素
- **容易出错**：索引越界、忘记更新计数、字符串截断……

C++ 的容器帮我们解决这些问题。

## 一、从 `vector` 到迭代器

### 1.1 两种遍历方式：索引 vs 迭代器

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    vector<string> names = {"Alice", "Bob", "Charlie", "Diana"};

    // 方式1：索引（来自 C 语言习惯）
    cout << "=== 索引遍历（像 C 的数组） ===" << endl;
    for (vector<string>::size_type i = 0; i < names.size(); ++i) {
        cout << "  names[" << i << "] = " << names[i] << endl;
    }

    // 方式2：迭代器（C++ 新方式，更通用）
    cout << "=== 迭代器遍历（所有容器通用） ===" << endl;
    for (vector<string>::const_iterator it = names.begin();
         it != names.end(); ++it) {
        cout << "  " << *it << endl;  // *it 解引用，类似 C 的 *ptr
    }

    // 方式3：auto + 迭代器（C++11 简化）
    cout << "=== auto 简化 ===" << endl;
    for (auto it = names.begin(); it != names.end(); ++it) {
        cout << "  " << it->c_str() << " (长度=" << it->size() << ")" << endl;
    }

    // ★ 迭代器和 C 指针的类比 ★
    int arr[] = {10, 20, 30, 40};
    int* p = arr;  // C 指针 → 指向数组开头
    cout << "\nC 指针遍历: ";
    while (p != arr + 4) {  // arr+4 是"尾后"位置
        cout << *p << " ";  // *p 解引用
        ++p;                // 移动到下一个
    }
    cout << "\n迭代器就是这些操作的标准化封装！" << endl;

    return 0;
}
```

`★ Insight ─────────────────────────────────────`
**迭代器就是 C 指针的泛化**。如果你理解 `int* p = arr; *p; ++p`，你就理解了迭代器的核心思想：
- `arr` → `v.begin()`（指向第一个元素）
- `arr + n` → `v.end()`（指向最后一个元素的**下一个**位置）
- `*p` → `*it`（解引用）
- `++p` → `++it`（移动到下一个）

区别在于：迭代器是**类型安全**的（`vector<int>::iterator` 不能赋给 `vector<string>::iterator`），并且适用于所有容器。

## 二、实际问题：将学生分类

### 2.1 场景描述

期末考试后，需要把学生分为两类：**及格**（≥60分）和**不及格**（<60分）。

回顾我们在第一周写的成绩计算程序，现在要扩展它来处理**多个学生的成绩分类**。

### 2.2 方案一：创建两个 vector（简单但低效）

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

struct Student_info {
    string name;
    double final_grade;
};

bool fgrade(const Student_info& s) {
    return s.final_grade < 60;  // 不及格
}

// 方案1：创建一个新的 pass vector（需要双倍内存）
vector<Student_info> extract_fails_v1(vector<Student_info>& students) {
    vector<Student_info> pass, fail;

    for (auto i = 0; i < students.size(); ++i) {
        if (fgrade(students[i]))
            fail.push_back(students[i]);
        else
            pass.push_back(students[i]);
    }
    students = pass;  // 用 pass 替换原容器
    return fail;
}

int main() {
    vector<Student_info> students = {
        {"Alice", 85}, {"Bob", 55}, {"Charlie", 92},
        {"Diana", 48}, {"Eve", 73}, {"Frank", 58}
    };

    cout << "=== 学生成绩分类 ===" << endl;
    cout << "原始学生列表 (" << students.size() << "人):" << endl;
    for (const auto& s : students) {
        cout << "  " << s.name << ": " << s.final_grade
             << (fgrade(s) ? " ❌ 不及格" : " ✅") << endl;
    }

    auto fails = extract_fails_v1(students);

    cout << "\n不及格学生 (" << fails.size() << "人):" << endl;
    for (const auto& s : fails)
        cout << "  " << s.name << ": " << s.final_grade << endl;

    cout << "及格学生 (" << students.size() << "人):" << endl;
    for (const auto& s : students)
        cout << "  " << s.name << ": " << s.final_grade << endl;

    return 0;
}
```

> 缺点：需要同时保存每个学生的两份副本，浪费内存。

### 2.3 方案二：原地删除（节约内存但 vector 效率低）

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct Student_info {
    string name;
    double final_grade;
};
bool fgrade(const Student_info& s) { return s.final_grade < 60; }

// 方案2：使用 erase() 原地删除
vector<Student_info> extract_fails_v2(vector<Student_info>& students) {
    vector<Student_info> fail;

    for (auto it = students.begin(); it != students.end(); ) {
        if (fgrade(*it)) {
            fail.push_back(*it);
            it = students.erase(it);  // erase 返回下一个有效迭代器
        } else {
            ++it;
        }
    }
    return fail;
}

int main() {
    vector<Student_info> students = {
        {"Alice", 85}, {"Bob", 55}, {"Charlie", 92}, {"Diana", 48}
    };

    auto fails = extract_fails_v2(students);

    cout << "及格: ";
    for (const auto& s : students) cout << s.name << " ";
    cout << "\n不及格: ";
    for (const auto& s : fails) cout << s.name << " ";
    cout << endl;

    // ★ 效率分析 ★
    cout << "\n--- vector 的插入/删除效率 ---" << endl;
    cout << "vector::erase() 删除中间元素后，需要移动后面所有元素" << endl;
    cout << "O(n) 复杂度！如果有1000个学生，删除第1个需要移动999个" << endl;
    return 0;
}
```

## 三、`list` — 高效插入和删除

`list` 是**双向链表**。每个元素独立分配，通过指针连接。插入和删除是 O(1)。

```cpp {cmd=true}
#include <iostream>
#include <list>
#include <string>
using namespace std;

struct Student_info {
    string name;
    double final_grade;
};
bool fgrade(const Student_info& s) { return s.final_grade < 60; }

// 使用 list：代码几乎一样，但删除效率高得多！
list<Student_info> extract_fails(list<Student_info>& students) {
    list<Student_info> fail;

    for (auto it = students.begin(); it != students.end(); ) {
        if (fgrade(*it)) {
            fail.push_back(*it);
            it = students.erase(it);  // O(1) 删除！
        } else {
            ++it;
        }
    }
    return fail;
}

int main() {
    list<Student_info> students = {
        {"Alice", 85}, {"Bob", 55}, {"Charlie", 92}, {"Diana", 48}
    };

    auto fails = extract_fails(students);

    cout << "及格: ";
    for (const auto& s : students) cout << s.name << " ";
    cout << "\n不及格: ";
    for (const auto& s : fails) cout << s.name << " ";
    cout << endl;

    // list 排序用成员函数 sort()
    students.sort([](const auto& a, const auto& b) {
        return a.name < b.name;
    });

    cout << "排序后: ";
    for (const auto& s : students) cout << s.name << " ";
    cout << endl;

    return 0;
}
```

### `vector` vs `list` 对比

| 特性 | `vector` | `list` |
|---|---|---|
| 底层结构 | 连续数组（动态） | 双向链表 |
| 随机访问 `v[i]` | ✅ O(1) | ❌ 不支持 |
| 尾部插入/删除 | ✅ O(1)（均摊） | ✅ O(1) |
| 中间插入/删除 | ❌ O(n) | ✅ O(1) |
| 内存占用 | 紧凑（无额外指针） | 每个元素多了两个指针 |
| 遍历速度 | 快（缓存友好） | 慢（指针跳转） |
| 排序 | `std::sort()` | `list::sort()`（成员函数） |

> **经验法则**：默认用 `vector`。只有当需要在中间频繁插入/删除时才考虑 `list`。

## 四、`map` — 关联容器

### 4.1 从 C 的角度理解 map

```c
// C 语言：做"名字→成绩"的映射？
// 只能用两个并行的数组，手动搜索……
char names[100][50];
int scores[100];
// 查 Alice 的成绩：遍历整个数组找匹配的名字 → O(n)
```

C++ 的 `map` 直接提供了键值映射，内部使用红黑树，查找 O(log n)。

### 4.2 实际场景：学生成绩查询系统

```cpp {cmd=true}
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    // 姓名 → 成绩的映射
    map<string, double> gradebook;

    // 插入成绩
    gradebook["Alice"]   = 85.5;
    gradebook["Bob"]     = 72.0;
    gradebook["Charlie"] = 93.5;
    gradebook["Diana"]   = 58.0;

    // 也可以用 insert
    gradebook.insert({"Eve", 88.0});

    cout << "=== 成绩查询系统 ===" << endl;
    cout << "请输入姓名查询成绩（输入 quit 退出）" << endl;

    // 模拟查询
    string queries[] = {"Bob", "Frank", "Alice", "quit"};
    for (const auto& q : queries) {
        if (q == "quit") break;
        cout << "查询: " << q << " → ";

        auto it = gradebook.find(q);
        if (it != gradebook.end()) {
            cout << it->second << "分" << endl;
        } else {
            cout << "未找到该学生" << endl;
        }
    }

    // 遍历所有学生（自动按 key 排序）
    cout << "\n=== 全班成绩单（按姓名排序） ===" << endl;
    for (const auto& entry : gradebook) {
        cout << "  " << entry.first << ": " << entry.second;
        if (entry.second >= 60)
            cout << " ✅" << endl;
        else
            cout << " ❌ 不及格" << endl;
    }

    // ★ C 语言对比 ★
    cout << "\n--- C vs C++ 对比 ---" << endl;
    cout << "C:   需要两个并行数组 + 自己写搜索/排序" << endl;
    cout << "C++: map<string, double> 自动排序、O(log n) 查找" << endl;

    return 0;
}
```

### 4.3 `map` 常用方法

| 方法 | 说明 |
|---|---|
| `m[k] = v` | 插入或更新键值对（k 不存在则插入） |
| `m.insert({k, v})` | 插入（k 已存在则不覆盖） |
| `m.emplace(k, v)` | 原地构造插入（C++11，最高效） |
| `m.at(k)` | 访问元素（k 不存在则抛出异常） |
| `m.find(k)` | 查找，返回迭代器（未找到返回 `end()`） |
| `m.erase(k)` | 删除键 k |
| `m.size()` | 键值对个数 |
| `m.clear()` | 清空 |

## 五、实际场景：统计词频

这是容器和迭代器综合应用的好例子。实现一个简单的词频统计程序。

```cpp {cmd=true}
#include <iostream>
#include <map>
#include <string>
#include <vector>
#include <sstream>
#include <algorithm>
using namespace std;

int main() {
    string text = "the quick brown fox jumps over the lazy dog "
                  "the fox is quick and the dog is lazy";

    map<string, int> word_count;
    istringstream iss(text);
    string word;

    // 统计每个单词的出现次数
    while (iss >> word) {
        // 转小写（简化处理）
        for (auto& c : word) c = tolower(c);
        ++word_count[word];  // 不存在则自动插入并初始化为0
    }

    cout << "=== 词频统计 ===" << endl;
    for (const auto& entry : word_count) {
        cout << "  " << entry.first << ": " << entry.second << endl;
    }

    // 找出出现次数最多的词
    auto max_it = max_element(word_count.begin(), word_count.end(),
        [](const auto& a, const auto& b) {
            return a.second < b.second;
        });

    cout << "\n出现最多的词: \"" << max_it->first
         << "\" (" << max_it->second << "次)" << endl;

    return 0;
}
```

## 六、迭代器操作速查

| 操作 | 说明 | 类比 C 指针 |
|---|---|---|
| `*it` | 解引用，获取元素 | `*p` |
| `it->member` | 访问成员 | `p->member` |
| `++it` | 移动到下一个 | `++p` |
| `--it` | 移动到上一个（双向） | `--p` |
| `it1 == it2` | 比较是否指向同一位置 | `p1 == p2` |
| `it1 != it2` | 比较是否指向不同位置 | `p1 != p2` |
| `it + n` | 移动 n 步（随机访问） | `p + n` |

## 七、第三周总结

| 知识点 | 说明 | C 语言对应 |
|---|---|---|
| `vector<T>` | 动态数组 | 手动 `malloc/realloc` + 数组 |
| `list<T>` | 双向链表 | 手写链表 `struct node { ... node* next; }` |
| `map<K, V>` | 键值映射，自动排序 | 两个并行数组 + 自己实现查找 |
| **迭代器** | 统一的元素遍历接口 | 指针（但更安全、更通用） |
| `erase(it)` | 删除迭代器指向的元素 | 手动移动后续元素 |
| `push_back(e)` | 在末尾添加元素 | `arr[count++] = e`（可能越界！） |
