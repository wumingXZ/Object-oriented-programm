## 〇、回顾第03周：你已经知道的

在第 03 周，你学习了：
- `vector` — 连续存储，索引访问 O(1)，中间插入 O(n)
- `list` — 链式存储，任意位置插入 O(1)，不能索引访问
- `map` — 键值对，按键自动排序，查找 O(log n)

但标准库提供的远不止这些。本文介绍 **set**（去重集合）、**multiset/multimap**（允许重复键）、**unordered_map**（哈希表）、以及 **stack/queue/priority_queue** 三个容器适配器。

2. 如果 map 的键允许重复（比如一个人拥有多部车），怎么办？
3. 如果不需要排序，只需要最快的查找速度，应该用什么？

这些正是本文要回答的问题。

## 一、`set` — 不重复元素的集合

### 1.1 基本操作

```cpp {cmd=true}
#include <iostream>
#include <set>
#include <vector>
using namespace std;

int main() {
    // set：元素唯一、自动排序
    set<int> s{3, 1, 4, 1, 5, 9, 2, 6, 5};

    cout << "set (自动去重+排序): ";
    for (auto x : s) cout << x << " ";  // 1 2 3 4 5 6 9
    cout << endl;

    // 插入（插入重复元素会被忽略）
    auto result = s.insert(4);
    cout << "插入 4: " << (result.second ? "成功" : "已存在") << endl;

    result = s.insert(7);
    cout << "插入 7: " << (result.second ? "成功" : "已存在") << endl;

    // 查找元素
    if (s.find(5) != s.end()) {
        cout << "找到 5" << endl;
    }

    // 删除元素
    s.erase(3);
    cout << "删除 3 后: ";
    for (auto x : s) cout << x << " ";
    cout << endl;

    // count: 元素是否存在（对 set 只有 0 或 1）
    cout << "5 出现次数: " << s.count(5) << endl;
    cout << "100 出现次数: " << s.count(100) << endl;

    return 0;
}
```

### 1.2 `set` 的实际应用：去重和快速查找

```cpp {cmd=true}
#include <iostream>
#include <set>
#include <vector>
#include <string>
using namespace std;

int main() {
    // 场景：统计文章中出现的所有不重复单词
    vector<string> words{"the", "quick", "brown", "fox",
                          "jumps", "over", "the", "lazy", "dog"};

    // set 自动去重 + 按字母排序
    set<string> unique_words(words.begin(), words.end());

    cout << "不重复单词 (" << unique_words.size() << " 个): ";
    for (const auto &w : unique_words) {
        cout << w << " ";
    }
    cout << endl;

    // 排除常用词（stop words）
    set<string> stop_words{"the", "a", "an", "in", "on", "over"};
    cout << "排除 stop words 后: ";
    for (const auto &w : unique_words) {
        if (stop_words.find(w) == stop_words.end()) {
            cout << w << " ";
        }
    }
    cout << endl;

    return 0;
}
```

## 二、`multiset` 和 `multimap` — 允许重复键

```cpp {cmd=true}
#include <iostream>
#include <map>
#include <set>
#include <string>
using namespace std;

int main() {
    // multiset：允许重复元素
    multiset<int> ms{1, 1, 2, 3, 3, 3, 5, 8};
    cout << "multiset: ";
    for (auto x : ms) cout << x << " ";
    cout << endl;
    cout << "3 出现了 " << ms.count(3) << " 次" << endl;

    // multimap：一个键可以对应多个值
    // 场景：一个作者可以有多本书
    multimap<string, string> authors;

    authors.insert({"金庸", "射雕英雄传"});
    authors.insert({"金庸", "天龙八部"});
    authors.insert({"金庸", "笑傲江湖"});
    authors.insert({"古龙", "多情剑客无情剑"});
    authors.insert({"古龙", "楚留香传奇"});

    // 查找某个作者的所有作品
    cout << "\n金庸的作品:" << endl;
    auto range = authors.equal_range("金庸");  // 返回 pair<iter, iter>
    for (auto it = range.first; it != range.second; ++it) {
        cout << "  - " << it->second << endl;
    }

    // 遍历整个 multimap
    cout << "\n所有作者和作品:" << endl;
    for (const auto &entry : authors) {
        cout << "  " << entry.first << ": " << entry.second << endl;
    }

    return 0;
}
```

## 三、无序容器 `unordered_map` / `unordered_set`（C++11）

```cpp {cmd=true}
#include <iostream>
#include <unordered_map>
#include <unordered_set>
#include <string>
using namespace std;

int main() {
    // unordered_map：基于哈希表，O(1) 平均查找
    unordered_map<string, int> word_count;

    // 插入和访问
    word_count["hello"] = 1;
    word_count["world"] = 2;
    word_count["hello"]++;  // hello → 2

    cout << "unordered_map 内容（无序）:" << endl;
    for (const auto &pair : word_count) {
        cout << "  " << pair.first << " → " << pair.second << endl;
    }

    // unordered_set：不重复、无序
    unordered_set<int> us{3, 1, 4, 1, 5, 9, 2, 6, 5};
    cout << "unordered_set: ";
    for (auto x : us) cout << x << " ";  // 顺序不确定
    cout << endl;

    // 性能对比
    cout << "\nbucket_count: " << word_count.bucket_count() << endl;
    cout << "load_factor: " << word_count.load_factor() << endl;

    return 0;
}
```

### `map` vs `unordered_map` 对比

| 特性 | `map` | `unordered_map` |
|---|---|---|
| 底层结构 | 红黑树（平衡二叉搜索树） | 哈希表（数组+链表） |
| 元素顺序 | 按键排序 | 无序 |
| 查找 | O(log n) | O(1) 平均，O(n) 最坏 |
| 插入 | O(log n) | O(1) 平均 |
| 内存占用 | 较少 | 较多（哈希桶） |
| 何时使用 | 需要有序遍历 | 只需快速查找，不关心顺序 |

**理解哈希表（unordered_map）：** 和无序容器的关键在于"哈希函数"——它把键（比如字符串）映射成一个整数（桶号），然后在对应的桶里查找。好的哈希函数让元素均匀分布，查找接近 O(1)；坏的哈希函数让元素挤在少数桶里，退化为 O(n)。标准库已经为 `int`、`string` 等内置类型提供了高质量的哈希函数，绝大多数场景直接使用即可。

## 四、容器适配器：`stack`、`queue`、`priority_queue`

这三个不是独立的容器，而是**适配器**——它们在底层容器（默认 `deque` 或 `vector`）之上，提供受限的接口。

> **设计思想：** 适配器模式是一种经典的软件设计模式——通过限制接口，使容器的行为符合特定数据结构的要求。例如栈只暴露 `push`/`pop`/`top`，而隐藏了 `insert`/`erase`/`[]` 等底层容器的全部功能。这种"限制"实际上是一种保护——降低了误用的可能，也使代码意图更加清晰。

### 4.1 `stack` — 栈

```cpp {cmd=true}
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    stack<int> st;

    // 入栈
    st.push(10);
    st.push(20);
    st.push(30);

    cout << "栈顶: " << st.top() << endl;
    cout << "大小: " << st.size() << endl;

    // 出栈
    cout << "出栈顺序: ";
    while (!st.empty()) {
        cout << st.top() << " ";  // 30 20 10（后进先出）
        st.pop();
    }
    cout << endl;

    // 实际应用：括号匹配
    string expr = "((a+b)*(c-d))";
    stack<char> parens;
    bool balanced = true;

    for (char c : expr) {
        if (c == '(') parens.push(c);
        else if (c == ')') {
            if (parens.empty()) { balanced = false; break; }
            parens.pop();
        }
    }
    balanced = balanced && parens.empty();
    cout << expr << " 括号匹配: " << (balanced ? "是" : "否") << endl;

    return 0;
}
```

### 4.2 `queue` — 队列

```cpp {cmd=true}
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // 入队
    q.push(10);
    q.push(20);
    q.push(30);

    cout << "队首: " << q.front() << endl;
    cout << "队尾: " << q.back() << endl;

    // 出队
    cout << "出队顺序: ";
    while (!q.empty()) {
        cout << q.front() << " ";  // 10 20 30（先进先出）
        q.pop();
    }
    cout << endl;

    return 0;
}
```

### 4.3 `priority_queue` — 优先队列

```cpp {cmd=true}
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    // 默认：大顶堆（最大元素在队首）
    priority_queue<int> pq;

    pq.push(30);
    pq.push(10);
    pq.push(50);
    pq.push(20);
    pq.push(40);

    cout << "优先级出队顺序: ";
    while (!pq.empty()) {
        cout << pq.top() << " ";  // 50 40 30 20 10
        pq.pop();
    }
    cout << endl;

    // 小顶堆：使用 greater<> 比较器
    priority_queue<int, vector<int>, greater<int>> min_pq;

    min_pq.push(30);
    min_pq.push(10);
    min_pq.push(50);

    cout << "小顶堆出队: ";
    while (!min_pq.empty()) {
        cout << min_pq.top() << " ";  // 10 30 50
        min_pq.pop();
    }
    cout << endl;

    return 0;
}
```

| 适配器 | 默认底层容器 | 核心操作 | 特点 |
|---|---|---|---|
| `stack` | `deque` | `push`, `pop`, `top` | LIFO（后进先出） |
| `queue` | `deque` | `push`, `pop`, `front`, `back` | FIFO（先进先出） |
| `priority_queue` | `vector` | `push`, `pop`, `top` | 按优先级出队 |

## 五、迭代器失效问题

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <list>
using namespace std;

int main() {
    // ⚠️ vector：插入/删除可能导致迭代器失效
    vector<int> v{1, 2, 3, 4, 5};

    cout << "=== vector 删除导致的迭代器失效 ===" << endl;
    // 错误示范：
    // for (auto it = v.begin(); it != v.end(); ++it) {
    //     if (*it % 2 == 0)
    //         v.erase(it);  // ❌ it 失效了！++it 是未定义行为
    // }

    // 正确方式：使用 erase 返回的下一个有效迭代器
    for (auto it = v.begin(); it != v.end(); ) {
        if (*it % 2 == 0) {
            it = v.erase(it);  // ✅ erase 返回下一个有效迭代器
        } else {
            ++it;
        }
    }
    cout << "删除偶数后: ";
    for (auto x : v) cout << x << " ";  // 1 3 5
    cout << endl;

    // list 的迭代器在插入/删除时更稳定
    list<int> lst{1, 2, 3, 4, 5};
    auto it = lst.begin();
    ++it; ++it;  // 指向 3

    lst.push_front(0);
    lst.push_back(6);

    // list 的迭代器不因 push_front/push_back 而失效
    cout << "仍然指向: " << *it << endl;

    return 0;
}
```

> **迭代器失效规则速记：**
> - `vector`/`string`：插入可能导致所有迭代器失效（可能扩容），删除导致被删元素之后的迭代器失效
> - `deque`：插入在两端外可能导致所有迭代器失效，删除类似
> - `list`/`forward_list`：插入不失效，删除仅被删元素的迭代器失效
> - `map`/`set`：插入不失效，删除仅被删元素的迭代器失效

## 六、`emplace` 系列操作（C++11）

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <map>
#include <string>
using namespace std;

int main() {
    // emplace_back 直接在容器内构造对象，避免拷贝
    vector<string> v;

    // push_back：先构造临时对象，再拷贝/移动到容器
    string s = "hello";
    v.push_back(s);         // 拷贝

    // emplace_back：直接传递构造函数参数
    v.emplace_back("world"); // 直接在容器内构造 string("world")
    v.emplace_back(5, '!');  // 直接在容器内构造 string(5, '!') → "!!!!!"

    cout << "vector: ";
    for (const auto &x : v) cout << x << " ";
    cout << endl;

    // map 的 emplace
    map<string, int> scores;
    scores.emplace("Alice", 85);    // 直接构造 pair
    scores.emplace("Bob", 92);

    for (const auto &p : scores) {
        cout << p.first << " → " << p.second << endl;
    }

    return 0;
}
```

> **何时用 `emplace`？** 当你要往容器里"创建"一个新对象时，用 `emplace` 比 `push`/`insert` 更高效——少了一次临时对象的构造和析构。

## 七、补充总结

### 核心要点

| 知识点 | 关键结论 |
|---|---|
| `set` | 不重复 + 自动排序，适合去重和集合运算 |
| `multimap` | 允许重复键，用 `equal_range` 遍历同一键的所有值 |
| `unordered_map` | 哈希表，O(1) 查找，不保证顺序 |
| 容器适配器 | `stack`(LIFO)、`queue`(FIFO)、`priority_queue`(按优先级) |
| 迭代器失效 | `vector` 扩容导致全失效，`list` 最稳定 |
| `emplace` | 原地构造，比 `push`/`insert` 高效 |

### 选择容器的决策树

```
需要按键快速查找？
├── 是 → 需要排序遍历？
│        ├── 是 → map / set
│        └── 否 → unordered_map / unordered_set
└── 否 → 需要什么操作？
         ├── 尾部增删 → vector
         ├── 任意位置增删 → list
         ├── 两端增删 → deque
         ├── LIFO → stack
         ├── FIFO → queue
         └── 按优先级 → priority_queue
```
