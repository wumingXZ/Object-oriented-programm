## 一、回顾："三法则"是什么？

第六周讲过的三个关键操作：**析构函数**、**拷贝构造函数**、**拷贝赋值运算符**。如果自定义了其中任意一个，通常三者都需要定义。

C++11 扩展为"五法则"——加上**移动构造函数**和**移动赋值运算符**。

## 二、左值和右值

### 2.1 基本概念

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <utility>
using namespace std;

int main() {
    int i = 42;         // i 是左值：有名字，可取地址
    int &r = i;         // r 是左值引用

    // int &&rr = i;    // ❌ 右值引用不能绑定到左值
    int &&rr = 42;      // ✅ 右值引用绑定到临时量（字面量）
    int &&rr2 = i * 2;  // ✅ 右值引用绑定到表达式结果

    // 左值持久；右值短暂（表达式结束后就消失）
    int *p = &i;  // ✅ 左值有地址
    // int *p2 = &(i * 2);  // ❌ 右值没有地址

    cout << "i=" << i << ", r=" << r
         << ", rr=" << rr << ", rr2=" << rr2 << endl;

    return 0;
}
```

| | 左值 (lvalue) | 右值 (rvalue) |
|---|---|---|
| 身份 | 有名字，有地址 | 临时的，无地址 |
| 生命周期 | 持续到作用域结束 | 表达式结束就销毁 |
| 引用绑定 | `T&` | `T&&` |
| 例子 | 变量、解引用结果 | 字面量、表达式临时结果 |

> **简单判断：能用 `&` 取地址的就是左值。**

### 2.2 `std::move` — 将左值转为右值

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <utility>
using namespace std;

int main() {
    string s1 = "Hello";
    cout << "移动前: s1 = \"" << s1 << "\"" << endl;

    // move 将左值转为右值引用（承诺"我不再使用 s1"）
    string s2 = move(s1);  // 移动构造——"窃取" s1 的资源

    cout << "移动后: s1 = \"" << s1 << "\"" << endl;  // s1 处于"有效但未指定"状态
    cout << "        s2 = \"" << s2 << "\"" << endl;  // s2 接管了 s1 的数据

    // ⚠️ 除了赋值和销毁，不要再使用被 move 的对象
    // 除非你重新给它赋值：
    s1 = "World";
    cout << "重新赋值后: s1 = \"" << s1 << "\"" << endl;

    return 0;
}
```

## 三、移动构造函数和移动赋值运算符

### 3.1 实现一个支持移动的类

```cpp {cmd=true}
#include <iostream>
#include <cstring>
#include <utility>
using namespace std;

class String {
private:
    char *data_ = nullptr;
    size_t size_ = 0;

public:
    // 默认构造函数
    String() = default;

    // 普通构造函数
    String(const char *s) : size_(strlen(s)) {
        data_ = new char[size_ + 1];
        strcpy(data_, s);
        cout << "  构造: \"" << data_ << "\"" << endl;
    }

    // 拷贝构造函数（深拷贝）
    String(const String &other) : size_(other.size_) {
        data_ = new char[size_ + 1];
        strcpy(data_, other.data_);
        cout << "  拷贝构造: \"" << data_ << "\"" << endl;
    }

    // 移动构造函数（"窃取"资源）— C++11
    String(String &&other) noexcept
        : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;  // 把原对象置于"可析构"状态
        other.size_ = 0;
        cout << "  移动构造: \"" << data_ << "\"" << endl;
    }

    // 拷贝赋值
    String &operator=(const String &other) {
        cout << "  拷贝赋值" << endl;
        if (this != &other) {
            delete[] data_;
            size_ = other.size_;
            data_ = new char[size_ + 1];
            strcpy(data_, other.data_);
        }
        return *this;
    }

    // 移动赋值 — C++11
    String &operator=(String &&other) noexcept {
        cout << "  移动赋值" << endl;
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    // 析构函数
    ~String() {
        delete[] data_;
        if (data_) cout << "  析构: \"" << data_ << "\"" << endl;
    }

    const char *c_str() const { return data_ ? data_ : "(null)"; }
};

// 一个返回临时对象的函数
String make_string() {
    return String("临时字符串");
}

int main() {
    cout << "=== 移动构造演示 ===" << endl;
    {
        cout << "创建 s1:" << endl;
        String s1("Hello World");
        cout << "移动构造 s2:" << endl;
        String s2 = move(s1);
        cout << "s1 = \"" << s1.c_str() << "\"" << endl;
        cout << "s2 = \"" << s2.c_str() << "\"" << endl;
    }
    cout << "\n=== 函数返回（编译器自动移动） ===" << endl;
    {
        String s3 = make_string();  // 编译器会优化，通常不调用移动构造
        cout << "s3 = \"" << s3.c_str() << "\"" << endl;
    }
    cout << "\n=== 移动赋值演示 ===" << endl;
    {
        String s4("AAA");
        String s5("BBB");
        cout << "移动赋值 s4 = move(s5):" << endl;
        s4 = move(s5);
        cout << "s4 = \"" << s4.c_str() << "\" (接管了 BBB 的数据)" << endl;
    }
    return 0;
}
```

### 3.2 `noexcept` 为什么重要？

移动操作通常不应该抛异常——它只是指针的交换，"拿走"资源。标记 `noexcept` 有两个好处：

1. **编译器可以生成更高效的代码**
2. **标准库容器在扩容时优先使用移动而非拷贝**——如果移动操作没有 `noexcept`，`vector` 扩容时会退化为拷贝！

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    // string 的移动构造函数标记了 noexcept
    // → vector 扩容时会移动而非拷贝
    vector<string> v;
    v.push_back("Hello");
    v.push_back("World");
    v.push_back("C++");

    cout << "size: " << v.size()
         << ", capacity: " << v.capacity() << endl;

    // 当 v.push_back 触发扩容时，旧元素被**移动**到新内存
    // 如果 string 的移动不是 noexcept，旧元素会被**拷贝**！

    return 0;
}
```

## 四、`= default` 和 `= delete`

```cpp {cmd=true}
#include <iostream>
using namespace std;

// C++11 新语法：显式要求编译器生成或删除函数
class Demo {
public:
    Demo() = default;                     // 显式要求编译器生成默认构造函数
    Demo(const Demo &) = default;         // 显式要求编译器生成拷贝构造函数
    Demo(Demo &&) noexcept = default;     // 显式要求编译器生成移动构造函数

    Demo &operator=(const Demo &) = default;  // 显式要求拷贝赋值
    Demo &operator=(Demo &&) noexcept = default;  // 显式要求移动赋值

    ~Demo() = default;                    // 显式要求编译器生成析构函数

    // 禁止拷贝
    // Demo(const Demo &) = delete;       // 删除拷贝构造
    // Demo &operator=(const Demo &) = delete; // 删除拷贝赋值
};

// 实用案例：不可拷贝的类（如文件句柄、网络连接）
class NonCopyable {
public:
    NonCopyable() = default;

    // 删掉拷贝操作
    NonCopyable(const NonCopyable &) = delete;
    NonCopyable &operator=(const NonCopyable &) = delete;

    // 但保留移动操作
    NonCopyable(NonCopyable &&) = default;
    NonCopyable &operator=(NonCopyable &&) = default;
};

int main() {
    Demo d1;
    Demo d2 = d1;           // ✅ 编译器生成的拷贝
    Demo d3 = move(d1);     // ✅ 编译器生成的移动

    NonCopyable nc1;
    // NonCopyable nc2 = nc1;  // ❌ 拷贝被删除
    NonCopyable nc3 = move(nc1);  // ✅ 移动仍然可用

    cout << "=default 和 =delete 演示完成" << endl;
    return 0;
}
```

## 五、从"三法则"到"五法则"

### C++98 三法则

如果自定义了**析构函数**、**拷贝构造**或**拷贝赋值**中的任意一个，通常三者都需要定义。

### C++11 五法则

加上**移动构造**和**移动赋值**。这些操作通常应该标记为 `noexcept`。

```cpp
class RuleOfFive {
public:
    // 三法则
    ~RuleOfFive();                                  // 1. 析构
    RuleOfFive(const RuleOfFive &);                 // 2. 拷贝构造
    RuleOfFive &operator=(const RuleOfFive &);      // 3. 拷贝赋值

    // 五法则（新增）
    RuleOfFive(RuleOfFive &&) noexcept;             // 4. 移动构造
    RuleOfFive &operator=(RuleOfFive &&) noexcept;  // 5. 移动赋值
};
```

### 零法则（现代 C++ 推荐）

如果你的类不直接管理资源（都用 `string`、`vector`、`unique_ptr` 等 RAII 类型），就不需要定义任何拷贝控制——编译器自动生成的版本就是正确的。

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ✅ 零法则：用 RAII 类型，编译器自动生成拷贝和移动都是正确的
class Student {
    string name;                      // string 自己管理拷贝/移动
    vector<double> scores;            // vector 自己管理拷贝/移动
    // 这些成员都是 RAII 类型，编译器生成的拷贝/移动/析构全自动正确！
};

int main() {
    Student s1;
    Student s2 = s1;       // ✅ 编译器生成的拷贝——正确（深拷贝 name 和 scores）
    Student s3 = move(s1); // ✅ 编译器生成的移动——正确（移动 name 和 scores）
    cout << "零法则演示: 编译器全自动处理拷贝和移动" << endl;
    return 0;
}
```

## 六、`std::move` 的正确用法

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <string>
#include <utility>
using namespace std;

int main() {
    // 场景1：将 string 移入容器（避免拷贝）
    vector<string> words;
    string s = "Hello World, this is a long string";
    words.push_back(move(s));  // s 的数据被"掏空"
    cout << "s after move: \"" << s << "\"" << endl;  // 空字符串

    // 场景2：交换两个对象（高效）
    string a = "AAAA", b = "BBBB";
    swap(a, b);  // 内部使用移动（如果类型支持）
    cout << "a=" << a << ", b=" << b << endl;

    // 场景3：从函数返回局部变量（自动移动，不需要显式 move）
    auto f = []() -> vector<int> {
        vector<int> v{1, 2, 3, 4, 5};
        return v;    // ✅ 编译器自动移动 v（NRVO：具名返回值优化，直接构造到调用方空间）
        // return move(v);  // ❌ 不要画蛇添足！会抑制 NRVO
    };
    auto result = f();
    cout << "result size: " << result.size() << endl;

    return 0;
}
```

> **⚠️ `return move(...)` 是常见的反模式！** 返回局部变量时编译器会自动进行移动（或 NRVO 优化），手动 `move` 反而可能抑制优化。

## 七、编译器自动生成规则速查

| 如果你定义了... | 编译器不再自动生成... |
|---|---|
| 任何构造函数 | 默认构造函数 |
| 析构函数 | 移动构造、移动赋值 |
| 拷贝构造 | 移动构造、移动赋值（但仍生成拷贝赋值⚠️） |
| 拷贝赋值 | 移动构造、移动赋值 |
| 移动构造 | 默认构造、拷贝构造、拷贝赋值 |
| 移动赋值 | 拷贝赋值（但拷贝构造仍可用） |

## 八、补充总结

### 核心要点

| 知识点 | 关键结论 |
|---|---|
| 左值/右值 | 左值持久有地址，右值短暂 |
| `std::move` | 左值→右值，承诺"我不再用它了" |
| 移动语义 | "窃取"资源而非拷贝——O(1) 代替 O(n) |
| `noexcept` | 移动操作必须标注，否则 vector 扩容用拷贝 |
| `=default` / `=delete` | 显式要求生成或禁用编译器生成的操作 |
| 五法则 | 析构/拷贝构造/拷贝赋值/移动构造/移动赋值 |
| 零法则 | 用 RAII 类型，让编译器自动处理一切 |
| 返回局部变量 | 不要 `return move(x)` |
