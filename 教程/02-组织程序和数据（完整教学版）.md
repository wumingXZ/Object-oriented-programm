## 一、用函数组织计算

### 1.1 为什么需要函数？

之前我们把计算逻辑直接写在 `main` 中：

```cpp
streamsize prec = cout.precision();
cout << "Your final grade is " << setprecision(3)
     << 0.2 * midterm + 0.4 * final + 0.4 * median
     << setprecision(prec) << endl;
```

用一个函数封装后：

```cpp
cout << "Your final grade is " << setprecision(3)
     << grade(midterm, final, median)
     << setprecision(prec) << endl;
```

更清晰，更易复用。

### 1.2 运行示例：计算成绩的函数

```cpp {cmd=true}
#include <iostream>
#include <iomanip>
using namespace std;

// 根据期中、期末和作业成绩计算最终成绩
double grade(double midterm, double final, double homework) {
    return 0.2 * midterm + 0.4 * final + 0.4 * homework;
}

int main() {
    cout << "期中 80, 期末 90, 作业 85" << endl;
    double result = grade(80, 90, 85);
    cout << "最终成绩: " << fixed << setprecision(1) << result << endl;
    return 0;
}
```

### 1.3 查找中值的函数

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <algorithm>
#include <stdexcept>
using namespace std;

// 计算 vector 的中值
// 注意：参数按值传递，函数内对 vec 的排序不影响调用者的原始数据
double median(vector<double> vec) {
    typedef vector<double>::size_type vec_sz;
    vec_sz size = vec.size();

    if (size == 0)
        throw domain_error("median of an empty vector");

    sort(vec.begin(), vec.end());
    vec_sz mid = size / 2;
    return (size % 2 == 0)
        ? (vec[mid] + vec[mid-1]) / 2
        : vec[mid];
}

int main() {
    vector<double> hw = {95, 88, 92, 90, 87, 93, 100};
    vector<double> original = hw;  // 保存原始数据

    double m = median(hw);
    cout << "中值: " << m << endl;

    cout << "原始数据未被修改: ";
    for (double x : original) cout << x << " ";
    cout << endl;
    return 0;
}
```

`★ Insight ─────────────────────────────────────`
注意 `median` 的参数是 `vector<double> vec`（**按值传递**），不是引用。这意味着函数内对 `vec` 的 `sort()` 操作的是**拷贝**，不影响调用者的原始数据。三种函数参数形式的选择原则：
1. **按值传递 `T`** — 需要拷贝，不改变实参
2. **const 引用 `const T&`** — 不拷贝，不改变实参
3. **非 const 引用 `T&`** — 不拷贝，可改变实参
`─────────────────────────────────────────────────`

## 二、异常处理 `try-catch`

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;

int main() {
    vector<double> empty_vec;
    vector<double> grades = {95, 88, 92};

    // 例1：捕获 domain_error 异常
    try {
        // 假设调用某个函数，它可能抛异常
        if (empty_vec.empty())
            throw domain_error("vector is empty!");
        cout << "这行不会执行" << endl;
    } catch (const domain_error& e) {
        cout << "捕获到异常: " << e.what() << endl;
    }

    // 例2：正常情况，不会抛异常
    try {
        if (!grades.empty())
            cout << "grades 的 size = " << grades.size() << endl;
        cout << "没有异常，正常执行" << endl;
    } catch (const domain_error& e) {
        cout << "不会到这里" << endl;
    }

    cout << "程序继续执行..." << endl;
    return 0;
}
```

| 关键字 | 说明 |
|---|---|
| `throw` | 抛出异常对象，程序停止在 throw 处 |
| `try { }` | 尝试执行可能产生异常的代码 |
| `catch(type e) { }` | 捕获特定类型的异常并处理 |
| `e.what()` | 获取异常的描述字符串 |

## 三、引用（Reference）

### 3.1 引用的基本概念

> 引用是标识符的**别名**。它不是一个独立的对象，而是已有对象的另一个名字。

```cpp {cmd=true}
#include <iostream>
using namespace std;

int main() {
    int original = 42;
    int& ref = original;  // ref 是 original 的引用（别名）

    cout << "original = " << original << ", ref = " << ref << endl;

    ref = 100;  // 通过引用修改
    cout << "ref = 100 后: original = " << original << endl;

    original = 200;  // 通过原始变量修改
    cout << "original = 200 后: ref = " << ref << endl;

    cout << "地址相同: &original = " << &original
         << ", &ref = " << &ref << endl;

    return 0;
}
```

### 3.2 引用作为函数参数

```cpp {cmd=true}
#include <iostream>
#include <vector>
using namespace std;

// 引用参数：不复制 but 可以修改实参
void addOne(vector<int>& v) {
    for (auto& x : v) x += 1;
}

// const 引用参数：不复制，也不能修改
void print(const vector<int>& v) {
    for (auto x : v) cout << x << " ";
    cout << endl;
}

int main() {
    vector<int> data = {1, 2, 3, 4, 5};
    cout << "原始: "; print(data);

    addOne(data);  // 传递引用，data 会被修改
    cout << "加1后: "; print(data);

    return 0;
}
```

### 3.3 返回引用的函数

```cpp {cmd=true}
#include <iostream>
using namespace std;

// 返回数组中第 index 个元素的引用
int& element(int a[], int index) {
    return a[index];  // 返回引用，不是值的拷贝！
}

int main() {
    int arr[] = {0, 2, 4, 6, 8};

    cout << "arr[3] = " << element(arr, 3) << endl;

    element(arr, 3) = 22;  // 赋值给引用 = 直接修改数组元素！
    cout << "element(arr, 3) = 22 后: arr[3] = " << arr[3] << endl;

    // 验证整个数组
    cout << "整个数组: ";
    for (int x : arr) cout << x << " ";
    cout << endl;

    return 0;
}
```

`★ Insight ─────────────────────────────────────`
返回引用的函数让函数调用可以出现在**赋值号的左边**——`element(arr, 3) = 22` 直接修改了数组元素。但**绝对不能返回局部变量的引用**：函数返回后局部变量已销毁，引用将悬空（dangling reference）。
`─────────────────────────────────────────────────`

### 3.4 引用 vs 指针

| | 引用 `T&` | 指针 `T*` |
|---|---|---|
| 初始化 | **必须**在定义时初始化 | 可以后赋值 |
| 重新绑定 | 不能 | 可以 |
| 空值 | 不存在空引用 | 有 `nullptr` |
| 语法 | 像普通变量 | 需要 `*p` 解引用 |
| 引用的引用 | 没有 | 有 `T**` |

## 四、函数重载（Overload）

```cpp {cmd=true}
#include <iostream>
#include <vector>
using namespace std;

// 重载版本1：传入单个 homework 值
double grade(double midterm, double final, double homework) {
    return 0.2 * midterm + 0.4 * final + 0.4 * homework;
}

// 重载版本2：传入 homework 的 vector
double grade(double midterm, double final, const vector<double>& hw) {
    if (hw.empty())
        throw domain_error("student has done no homework");
    // 计算平均值
    double sum = 0;
    for (double x : hw) sum += x;
    return grade(midterm, final, sum / hw.size());  // 调用版本1
}

int main() {
    // 调用版本1
    cout << "单个作业成绩: " << grade(80, 90, 85) << endl;

    // 调用版本2
    vector<double> hw = {95, 88, 92, 90, 87};
    cout << "多个作业成绩(平均): " << grade(80, 90, hw) << endl;

    return 0;
}
```

> 函数重载：**名字相同，参数不同**（个数或类型）。编译器根据调用时的实参自动选择正确的版本。

## 五、结构体：组织相关数据

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 将学生的所有相关数据组织在一起
struct Student_info {
    string name;
    double midterm, final;
    vector<double> homework;
};

int main() {
    Student_info s;

    s.name = "Alice";
    s.midterm = 85;
    s.final = 90;
    s.homework = {95, 88, 92, 90, 87};

    cout << "姓名: " << s.name << endl;
    cout << "期中: " << s.midterm << ", 期末: " << s.final << endl;
    cout << "作业成绩: ";
    for (double g : s.homework) cout << g << " ";
    cout << endl;

    // 结构体数组
    vector<Student_info> students;
    students.push_back(s);

    Student_info s2 = {"Bob", 78, 85, {80, 82, 88}};
    students.push_back(s2);

    cout << "\n所有学生:" << endl;
    for (const auto& stu : students) {
        cout << "  " << stu.name << " (期中:" << stu.midterm
             << " 期末:" << stu.final << ")" << endl;
    }

    return 0;
}
```

## 六、分文件编译

### 6.1 为什么要分文件？

- 每个文件可以**独立编译**，修改一个模块不需要重编译全部
- 接口（`.h` 头文件）与实现（`.cpp` 源文件）**分离**
- 大型程序组织的基础

### 6.2 运行示例：三个文件协同工作

以下是一个完整的分文件编译示例。在 MPE 中，我们可以将多个文件的内容合并在一个代码块中编译运行：

```cpp {cmd=true}
#include <iostream>
#include <vector>
#include <stdexcept>
#include <algorithm>
using namespace std;

// ===== median.h =====
#ifndef GUARD_median_h
#define GUARD_median_h
double median(vector<double> vec);
#endif

// ===== median.cpp =====
double median(vector<double> vec) {
    typedef vector<double>::size_type vec_sz;
    vec_sz size = vec.size();
    if (size == 0)
        throw domain_error("median of an empty vector");
    sort(vec.begin(), vec.end());
    vec_sz mid = size / 2;
    return (size % 2 == 0)
        ? (vec[mid] + vec[mid-1]) / 2
        : vec[mid];
}

// ===== main =====
int main() {
    vector<double> hw = {95, 88, 92, 90, 87, 93};
    cout << "中值: " << median(hw) << endl;
    return 0;
}
```

### 6.3 头文件保护符

```cpp
#ifndef GUARD_median_h  // 如果 GUARD_median_h 未定义
#define GUARD_median_h  // 就定义它

// 头文件内容 ...

#endif  // 结束条件编译
```

防止同一个头文件被多次包含导致重复定义错误。本项目约定格式为 `GUARD_xxx_h`。

### 6.4 文件清单

在实际项目中分文件编译的命令：

```bash
# 列出所有 .cpp 文件一起编译
g++ main.cpp Student_info.cpp median.cpp grade.cpp -o student.exe
```

项目文件组织：

| 文件 | 角色 |
|---|---|
| `median.h` | 声明 `median()` 函数 |
| `median.cpp` | 实现 `median()` 函数 |
| `Student_info.h` | 声明 `Student_info` 结构体和相关函数 |
| `Student_info.cpp` | 实现 `read()`、`compare()` 等函数 |
| `grade.h` | 声明 `grade()` 函数系列 |
| `grade.cpp` | 实现各重载版本 |
| `main.cpp` | 主程序入口 |

## 七、第二周总结

| 知识点 | 说明 |
|---|---|
| **函数** | 封装逻辑，复用代码 |
| **`throw` / `try` / `catch`** | 异常处理机制 |
| **引用 `T&`** | 别名，不拷贝，可修改原始对象 |
| **`const T&`** | 不拷贝，也不可修改——高效的只读传参 |
| **函数重载** | 同名不同参，编译器自动匹配 |
| **`struct`** | 组织相关数据为用户自定义类型 |
| **头文件 `.h`** | 声明接口；用 `#ifndef` 守卫防止重复包含 |
| **源文件 `.cpp`** | 包含实现，独立编译 |

### 三种函数形参模式速查

| 形参 | 拷贝？ | 修改实参？ | 适用场景 |
|---|---|---|---|
| `T param` | ✓ | ✗ | 小对象，需要在函数内修改副本 |
| `const T& param` | ✗ | ✗ | 大对象，只读访问（最常用） |
| `T& param` | ✗ | ✓ | 需要修改实参，或作为"输出"参数 |
