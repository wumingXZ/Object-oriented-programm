## 一、面向对象编程的核心思想

C++ 面向对象编程基于三大基石：

| 概念 | 含义 | 对应章节 |
|---|---|---|
| **数据抽象** | 将接口与实现分离 | 第七章（类） |
| **继承** | 定义相似类型之间的关系 | 本章 |
| **动态绑定** | 忽略类型差异，统一使用对象 | 本章 |

> **来自 C++ Primer 第 15 章**：通过继承，我们能够定义类来建模相似类型之间的关系；通过动态绑定，我们能够使用这些类型的对象，同时忽略它们的具体差异。

### 运行示例：感受多态

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
#include <memory>
using namespace std;

// 基类：动物
class Animal {
public:
    virtual string speak() const { return "???"; }
    virtual ~Animal() {}  // 虚析构函数！
};

// 派生类
class Dog : public Animal {
public:
    string speak() const override { return "汪汪!"; }
};

class Cat : public Animal {
public:
    string speak() const override { return "喵喵!"; }
};

int main() {
    vector<unique_ptr<Animal>> zoo;
    zoo.push_back(make_unique<Dog>());
    zoo.push_back(make_unique<Cat>());
    zoo.push_back(make_unique<Dog>());

    for (const auto& a : zoo) {
        cout << a->speak() << " ";  // 动态绑定！
    }
    cout << endl;
    return 0;
}
```

## 二、问题引入：学生成绩管理系统

### 2.1 需求变更

- 研究生除了完成家庭作业和考试外，还需要写一篇**论文（thesis）**
- 研究生的最终成绩 = **min(课程成绩, 论文成绩)**

### 2.2 设计与运行示例

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
#include <stdexcept>
using namespace std;

// 基类：本科生
class Core {
public:
    Core() : midterm(0), final(0) {}
    Core(istream& is) { read(is); }

    virtual ~Core() {}  // 虚析构函数

    string name() const { return n; }

    virtual double grade() const {
        if (homework.empty())
            throw runtime_error("no homework");
        return 0.2 * midterm + 0.4 * final + 0.4 * average(homework);
    }

    virtual istream& read(istream& is) {
        is >> n >> midterm >> final;
        read_hw(is);
        return is;
    }

protected:
    double midterm, final;
    vector<double> homework;
    istream& read_common(istream& is) {
        is >> n >> midterm >> final;
        return is;
    }

private:
    string n;

    void read_hw(istream& is) {
        homework.clear();
        double x;
        while (is >> x) homework.push_back(x);
        if (is.fail() && !is.eof()) throw runtime_error("bad input");
        is.clear();
    }

    double average(const vector<double>& v) const {
        if (v.empty()) return 0;
        double sum = 0;
        for (auto x : v) sum += x;
        return sum / v.size();
    }
};

// 派生类：研究生
class Grad : public Core {
public:
    Grad() : thesis(0) {}
    Grad(istream& is) { read(is); }

    double grade() const override {
        return min(Core::grade(), thesis);
    }

    istream& read(istream& is) override {
        read_common(is);
        is >> thesis;
        double x;
        homework.clear();
        while (is >> x) homework.push_back(x);
        is.clear();
        return is;
    }

private:
    double thesis;
};

// 使用示例
int main() {
    // 创建对象
    Core undergrad;
    Grad grad;

    cout << "=== 本科生和研究生示例 ===" << endl;
    cout << "本科生 Core 和研究生 Grad 是两个相关的类。" << endl;
    cout << "Grad 继承自 Core，并添加了 thesis 成员。" << endl;
    cout << endl;

    // 多态演示
    Core* p1 = new Core();
    Core* p2 = new Grad();

    cout << "p1 类型是 Core*，实际指向 Core" << endl;
    cout << "p2 类型是 Core*，实际指向 Grad" << endl;
    cout << "这就是多态的基础：基类指针可以指向派生类对象" << endl;

    delete p1;
    delete p2;

    return 0;
}
```

`★ Insight ─────────────────────────────────────`
`class Grad : public Core` 中的 `public` 表示**公有继承**：
- `Core` 的公有成员也成为 `Grad` 的公有成员
- `Grad` 的对象可以当作 `Core` 的对象来使用
- 构造函数、赋值操作符和析构函数**不会被继承**
`─────────────────────────────────────────────────`

## 三、保护标签 `protected`

```cpp {cmd=true}
#include <iostream>
#include <string>
using namespace std;

class Base {
public:
    int pub = 1;      // 所有人可访问

protected:
    int prot = 2;     // 自己和派生类可访问

private:
    int priv = 3;     // 只有自己能访问

public:
    void show() const {
        cout << "Base: pub=" << pub << ", prot=" << prot
             << ", priv=" << priv << endl;
    }
};

class Derived : public Base {
public:
    void access() {
        cout << "Derived 可以访问:" << endl;
        cout << "  pub = " << pub << endl;     // ✅
        cout << "  prot = " << prot << endl;    // ✅
        // cout << "  priv = " << priv << endl; // ❌ 编译错误
    }
};

int main() {
    Derived d;
    d.access();
    d.show();
    cout << "外部可以访问 pub = " << d.pub << endl;     // ✅
    // cout << "prot = " << d.prot << endl;  // ❌ 编译错误
    // cout << "priv = " << d.priv << endl;  // ❌ 编译错误
    return 0;
}
```

**三种访问级别对比**：

| 访问级别 | 类自身 | 派生类 | 外部用户 |
|---|---|---|---|
| `public` | ✓ | ✓ | ✓ |
| `protected` | ✓ | ✓ | ✗ |
| `private` | ✓ | ✗ | ✗ |

## 四、虚函数与动态绑定 — 核心机制

### 4.1 运行示例：静态绑定 vs 动态绑定

```cpp {cmd=true}
#include <iostream>
using namespace std;

class Base {
public:
    virtual void vfunc() const { cout << "Base::vfunc()" << endl; }
    void ordinary() const { cout << "Base::ordinary()" << endl; }
};

class Derived : public Base {
public:
    void vfunc() const override { cout << "Derived::vfunc()" << endl; }
    void ordinary() const { cout << "Derived::ordinary()" << endl; }
};

int main() {
    Derived d;
    Base* p = &d;
    Base& r = d;

    cout << "--- 通过对象调用（都是静态绑定）---" << endl;
    d.vfunc();       // Derived::vfunc()
    d.ordinary();    // Derived::ordinary()

    cout << "--- 通过指针调用 ---" << endl;
    p->vfunc();      // Derived::vfunc() — 动态绑定！
    p->ordinary();   // Base::ordinary()  — 非虚函数，静态绑定

    cout << "--- 通过引用调用 ---" << endl;
    r.vfunc();       // Derived::vfunc() — 动态绑定！
    r.ordinary();    // Base::ordinary()  — 非虚函数，静态绑定

    return 0;
}
```

**关键规则**：

| 调用方式 | 绑定时机 | 条件 |
|---|---|---|
| 通过**对象**调用 | 编译时（静态绑定） | 无 |
| 通过**指针**调用虚函数 | 运行时（动态绑定） | 函数必须是 virtual |
| 通过**引用**调用虚函数 | 运行时（动态绑定） | 函数必须是 virtual |

### 4.2 对象切片（Object Slicing）

```cpp {cmd=true}
#include <iostream>
using namespace std;

class Base {
public:
    virtual void info() const { cout << "Base (size=" << sizeof(*this) << ")" << endl; }
    int baseData[2] = {1, 2};
};

class Derived : public Base {
public:
    void info() const override { cout << "Derived (size=" << sizeof(*this) << ")" << endl; }
    int extraData[4] = {3, 4, 5, 6};
};

// ❌ 按值传递：会发生切片！
void printByValue(Base b) {
    b.info();
    cout << "  对象大小: " << sizeof(b) << " 字节 (被切片了!)" << endl;
}

// ✅ 按引用传递：保留完整类型
void printByRef(const Base& b) {
    b.info();
    cout << "  完整对象 (动态绑定有效)" << endl;
}

int main() {
    Derived d;
    cout << "原始 Derived 大小: " << sizeof(d) << " 字节" << endl << endl;

    cout << "按值传递: "; printByValue(d);
    cout << "按引用传递: "; printByRef(d);
    return 0;
}
```

`★ Insight ─────────────────────────────────────`
按值传参时发生**对象切片**：派生类对象的派生部分被"切掉"，只剩下基类部分。因此：
- 始终用**指针或引用**传递多态类型
- 容器应保存指针（如 `vector<Core*>`），不能保存值（`vector<Core>`）
`─────────────────────────────────────────────────`

## 五、使用继承解决学生成绩问题（完整程序）

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
#include <iomanip>
#include <stdexcept>
#include <memory>
#include <sstream>
using namespace std;

// ================ 基类 Core ================
class Core {
public:
    Core() : midterm(0), final(0) {}
    Core(istream& is) { read(is); }
    virtual ~Core() = default;

    string name() const { return n; }

    virtual double grade() const {
        if (homework.empty())
            throw runtime_error("student has done no homework");
        return 0.2 * midterm + 0.4 * final + 0.4 * average(homework);
    }

    virtual istream& read(istream& is) {
        is >> n >> midterm >> final;
        read_hw(is);
        return is;
    }

protected:
    istream& read_common(istream& is) {
        is >> n >> midterm >> final;
        return is;
    }
    double midterm, final;
    vector<double> homework;

private:
    string n;
    void read_hw(istream& is) {
        homework.clear();
        double x;
        while (is >> x) homework.push_back(x);
        is.clear();  // 清除 EOF 标志
    }
    static double average(const vector<double>& v) {
        double sum = 0;
        for (auto x : v) sum += x;
        return v.empty() ? 0 : sum / v.size();
    }
};

// ================ 派生类 Grad ================
class Grad : public Core {
public:
    Grad() : thesis(0) {}
    Grad(istream& is) { read(is); }

    double grade() const override {
        return min(Core::grade(), thesis);
    }

    istream& read(istream& is) override {
        read_common(is);
        is >> thesis;
        double x;
        homework.clear();
        while (is >> x) homework.push_back(x);
        is.clear();
        return is;
    }

private:
    double thesis;
};

// ================ 主程序 ================
int main() {
    vector<unique_ptr<Core>> students;

    // 用预置数据模拟输入
    cout << "=== 学生成绩报告系统 ===" << endl;
    cout << "输入格式: 类型(U/G) 姓名 期中 期末 [作业...] [论文(研究生)]" << endl;
    cout << endl;

    // 手动添加示例学生
    // 本科生: U Alice 85 90 95 88 92 90
    auto alice = make_unique<Core>();
    { istringstream iss("U Alice 85 90 95 88 92 90"); alice->read(iss); }
    students.push_back(move(alice));

    // 研究生: G Bob 80 85 88 82 90 86 92
    auto bob = make_unique<Grad>();
    { istringstream iss("G Bob 80 85 88 82 90 86 92"); bob->read(iss); }
    students.push_back(move(bob));

    // 另一个本科生
    auto charlie = make_unique<Core>();
    { istringstream iss("U Charlie 70 75 80 85 78 82"); charlie->read(iss); }
    students.push_back(move(charlie));

    // 另一个研究生
    auto diana = make_unique<Grad>();
    { istringstream iss("G Diana 90 92 100 98 88 95"); diana->read(iss); }
    students.push_back(move(diana));

    // 按姓名排序
    sort(students.begin(), students.end(),
         [](const auto& a, const auto& b) { return a->name() < b->name(); });

    // 打印报表
    for (const auto& s : students) {
        cout << left << setw(12) << s->name();
        try {
            double g = s->grade();  // 动态绑定！
            cout << fixed << setprecision(1) << g << endl;
        } catch (const runtime_error& e) {
            cout << "N/A (" << e.what() << ")" << endl;
        }
    }
    return 0;
}
```

## 六、虚析构函数

```cpp {cmd=true}
#include <iostream>
using namespace std;

class Base {
public:
    Base() { cout << "Base()" << endl; }
    virtual ~Base() { cout << "~Base()" << endl; }  // 虚析构函数
};

class Derived : public Base {
    int* data;
public:
    Derived() : data(new int[100]) {
        cout << "Derived() — 分配了100个int" << endl;
    }
    ~Derived() override {
        delete[] data;
        cout << "~Derived() — 释放了100个int" << endl;
    }
};

int main() {
    cout << "--- 创建 Derived 对象 ---" << endl;
    Base* p = new Derived();

    cout << "--- delete p (通过基类指针) ---" << endl;
    delete p;  // 如果 ~Base() 不是虚函数，~Derived() 不会被调用
               // data 将泄漏！但由于是虚析构函数，一切正常
    return 0;
}
```

> **C++ Primer 建议**：如果类可能作为基类使用，应定义虚析构函数——即使函数体为空。

## 七、纯虚函数和抽象类

```cpp {cmd=true}
#include <iostream>
#include <cmath>
using namespace std;

// 抽象基类：只定义接口
class Shape {
public:
    virtual double area() const = 0;   // 纯虚函数
    virtual double perimeter() const = 0;
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double r;
public:
    Circle(double radius) : r(radius) {}
    double area() const override { return M_PI * r * r; }
    double perimeter() const override { return 2 * M_PI * r; }
};

class Rectangle : public Shape {
    double w, h;
public:
    Rectangle(double width, double height) : w(width), h(height) {}
    double area() const override { return w * h; }
    double perimeter() const override { return 2 * (w + h); }
};

void printInfo(const Shape& s, const char* name) {
    cout << name << ": area=" << s.area()
         << ", perimeter=" << s.perimeter() << endl;
}

int main() {
    // Shape s;  // ❌ 错误！不能创建抽象类的对象

    Circle c(5);
    Rectangle r(3, 4);

    printInfo(c, "圆(半径5)");
    printInfo(r, "矩形(3×4)");
    return 0;
}
```

> 包含纯虚函数的类称为**抽象类**，不能实例化。派生类必须实现所有纯虚函数才能成为具体类。

## 八、`override` 和 `final` 关键字（C++11）

```cpp {cmd=true}
#include <iostream>
using namespace std;

class Animal {
public:
    virtual void eat() const { cout << "Animal eats" << endl; }
    virtual void sleep() const { cout << "Animal sleeps" << endl; }
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void eat() const override {    // ✅ 明确重写，编译器会检查
        cout << "Dog eats bones" << endl;
    }

    void sleep() const final {     // final: 禁止子类继续重写
        cout << "Dog sleeps in kennel" << endl;
    }

    // void eet() const override { }  // ❌ 编译错误！基类没有 eet()
};

class Puppy : public Dog {
public:
    void eat() const override {    // ✅ 可以重写
        cout << "Puppy eats puppy food" << endl;
    }

    // void sleep() const override { }  // ❌ 错误！Dog::sleep() 是 final
};

int main() {
    Puppy p;
    p.eat();
    p.sleep();
    return 0;
}
```

> **始终使用 `override`**：让它帮你发现签名不匹配的错误。这是零成本的安全网。

## 九、访问控制与继承总结

| 继承方式 | 基类成员 | 在派生类中 | 在派生类的派生类中 | 类外函数 |
|---|---|---|---|---|
| **公有继承** | public | public ✓ | public ✓ | ✓ |
| | protected | protected ✓ | protected ✓ | ✗ |
| | private | ✗ | ✗ | ✗ |
| **私有继承** | public | private ✓ | ✗ | ✗ |
| | protected | private ✓ | ✗ | ✗ |
| | private | ✗ | ✗ | ✗ |

> **实践中几乎总是使用公有继承**。

## 十、课程总结

| 知识点 | 关键要点 |
|---|---|
| **继承** | `class Grad : public Core`；派生类拥有基类的所有成员（构造/析构/赋值除外） |
| **`protected`** | 派生类可访问，外部不可访问 |
| **构造顺序** | 基类 → 派生类成员初始化 → 派生类构造函数体 |
| **虚函数 `virtual`** | 通过指针/引用实现动态绑定；按值传递会切片 |
| **多态** | 基类指针/引用可以指向派生类对象 |
| **虚析构函数** | 基类必须定义虚析构函数，确保正确清理 |
| **纯虚函数** | `= 0`；类成为抽象类，不能实例化 |
| **`override`** | 显式标记重写，编译时校验 |
| **`final`** | 阻止虚函数被继续重写 |

> **课后练习**：为 `Shape` 层次添加 `Triangle` 类。思考：`Triangle` 和 `Rectangle` 有哪些共性？是否需要引入中间基类？
