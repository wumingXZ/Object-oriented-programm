## 〇、C 语言回顾：struct 的局限性

C 语言的 struct 只是数据的"打包"：

```c
// C 语言方式
struct Student {
    char name[50];
    double midterm, final;
    double homework[20];
    int hw_count;
};

// 使用时数据和处理数据的函数是分离的
void read_student(struct Student* s) { ... }    // 函数和结构体分离
double grade_student(struct Student* s) { ... } // 没有封装，任何人都能直接修改 s->midterm

// 问题：
// 1. 数据和处理数据的函数分离
// 2. 任何人都能直接修改内部数据（无保护）
// 3. 无法保证数据有效性（如 hw_count 和 homework 数组可能不一致）
```

C++ 的 `class` 把**数据**和**操作数据的方法**绑在一起，并控制访问权限。

<a id="一从-struct-到-class"></a>
## 一、从 `struct` 到 `class`

### 1.1 C 风格 struct

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// C 风格：裸 struct，数据暴露在外
struct Student_info_C {
    string name;
    double midterm, final;
    vector<double> homework;
};

// 全局函数操作 struct
istream& read_C(istream& is, Student_info_C& s) {
    is >> s.name >> s.midterm >> s.final;  // 需要手动操作每个成员
    double x;
    while (is >> x) s.homework.push_back(x);
    is.clear();
    return is;
}

int main() {
    cout << "--- C 风格的 struct ---" << endl;
    Student_info_C s1 = {"Alice", 85, 90, {95, 88, 92}};  // 直接访问

    cout << "姓名: " << s1.name << endl;  // 任何人都能读
    s1.midterm = 999;  // 任何人都能改！可能破坏数据一致性
    cout << "被恶意修改的期中成绩: " << s1.midterm << endl;

    return 0;
}
```

> 问题：任何人都能直接读写 `s1.midterm`，可能被错误修改。

### 1.2 C++ class：封装

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
#include <stdexcept>
#include <sstream>
using namespace std;

class Student_info {
public:   // ===== 公有接口 =====
    // 构造函数（对象创建时自动调用）
    Student_info() : midterm(0), final(0) {}
    Student_info(istream& is) { read(is); }

    // 成员函数：通过对象隐式调用
    istream& read(istream& in) {
        in >> n >> midterm >> final;
        double x;
        homework.clear();
        while (in >> x) homework.push_back(x);
        in.clear();
        return in;
    }

    double grade() const {  // const：此函数不修改对象
        if (homework.empty())
            throw domain_error("no homework");
        double sum = 0;
        for (double h : homework) sum += h;
        double avg = sum / homework.size();
        return 0.2 * midterm + 0.4 * final + 0.4 * avg;
    }

    // 访问器（accessor）：以只读方式暴露数据
    string name() const { return n; }
    bool valid() const { return !homework.empty(); }

private:  // ===== 私有实现细节 =====
    string n;
    double midterm, final;
    vector<double> homework;
};

// compare 是非成员函数（它不修改对象，且操作对称）
bool compare(const Student_info& x, const Student_info& y) {
    return x.name() < y.name();
}

int main() {
    // 使用预置数据
    Student_info s;
    istringstream iss("Alice 85 90 95 88 92 90 87");
    s.read(iss);

    cout << "=== 封装后的 Student_info ===" << endl;
    cout << "姓名: " << s.name() << endl;
    cout << "数据有效性: " << (s.valid() ? "有效" : "无效") << endl;

    try {
        cout << "最终成绩: " << s.grade() << endl;
    } catch (const domain_error& e) {
        cout << "错误: " << e.what() << endl;
    }

    // s.midterm = 999;  // ❌ 编译错误！midterm 是 private
    // s.n = "hack";     // ❌ 编译错误！n 是 private
    cout << "\n私有成员不可从外部访问 ✋" << endl;

    return 0;
}
```

`★ Insight ─────────────────────────────────────`
**封装（Encapsulation）**是将接口与实现分离的过程。接口（`public` 部分）是类对外承诺的契约，一旦稳定就不轻易改变；实现（`private` 部分）可以随时优化改良，不影响使用该类的代码。这正是面向对象的四大支柱之一：**抽象、封装、继承、多态**。
`─────────────────────────────────────────────────`

<a id="二struct-vs-class"></a>
## 二、`struct` vs `class`

```cpp {cmd=true}
#include <iostream>
using namespace std;

// struct：默认 public
struct Point_S {
    int x, y;  // public（默认）
    void print() const { cout << "(" << x << "," << y << ")"; }
};

// class：默认 private
class Point_C {
    int x, y;  // private（默认）！
public:
    Point_C(int a, int b) : x(a), y(b) {}
    void print() const { cout << "(" << x << "," << y << ")"; }
};

int main() {
    Point_S ps = {10, 20};
    ps.x = 30;  // ✅ struct 默认可以访问
    cout << "struct: "; ps.print(); cout << endl;

    Point_C pc(10, 20);
    // pc.x = 30;  // ❌ class 默认不可访问
    cout << "class:  "; pc.print(); cout << endl;

    // 惯例：
    // struct → 简单数据类型，成员直接暴露
    // class  → 需要封装保护的复杂类型
    return 0;
}
```

| | `struct` | `class` |
|---|---|---|
| 默认访问级别 | `public` | `private` |
| 惯例用途 | 简单数据聚合 | 需要封装和行为 |
| 都可以有成员函数 | ✅ | ✅ |
| 都可以有构造函数 | ✅ | ✅ |
| 都可以继承 | ✅ | ✅ |

## 三、构造函数

构造函数是对象创建时**自动调用**的特殊成员函数。

```cpp {cmd=true}
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    // 默认构造函数：没有参数
    Student() : name_(""), score_(0) {
        cout << "默认构造: " << name_ << endl;
    }

    // 带参数的构造函数
    Student(const string& n, double s) : name_(n), score_(s) {
        cout << "参数构造: " << name_ << " (" << score_ << ")" << endl;
    }

    // 从输入流构造
    Student(istream& is) {
        is >> name_ >> score_;
        cout << "流构造: " << name_ << " (" << score_ << ")" << endl;
    }

    string name() const { return name_; }
    double score() const { return score_; }

private:
    string name_;
    double score_;
};

int main() {
    cout << "=== 构造函数演示 ===" << endl;

    Student s1;                            // 默认构造函数
    Student s2("Alice", 85);              // 带参数构造
    Student s3(cin);                      // 流构造（测试用：输入"Bob 92"）

    cout << "\n创建的对象:" << endl;
    cout << "s1: " << s1.name() << " " << s1.score() << endl;
    cout << "s2: " << s2.name() << " " << s2.score() << endl;
    // s3 依赖 cin 输入，此处略

    return 0;
}
```

### 构造函数的初始化列表

```cpp {cmd=true}
#include <iostream>
#include <string>
using namespace std;

class Example {
    const int ID;      // const 成员
    string& ref;       // 引用成员
    int normal;

public:
    // ✅ 正确：用初始化列表
    Example(int id, string& r, int n)
        : ID(id), ref(r), normal(n) {}

    // ❌ 不能这样写（const 和引用不能赋值）：
    // Example(int id, string& r, int n) {
    //     ID = id;   // 错误：const 成员不可赋值
    //     ref = r;   // 错误：引用不可重新绑定
    // }

    void show() const {
        cout << "ID=" << ID << ", ref=" << ref
             << ", normal=" << normal << endl;
    }
};

int main() {
    string str = "hello";
    Example e(42, str, 100);
    e.show();
    return 0;
}
```

> const 成员和引用成员**必须用初始化列表初始化**，因为它们在构造函数体执行前就已经存在。

### 对象创建过程

```
1. 系统分配内存空间
2. 按初始化列表初始化成员（按声明顺序，不是列表顺序！）
3. 执行构造函数体
```

<a id="四const-成员函数"></a>
## 四、`const` 成员函数

```cpp {cmd=true}
#include <iostream>
#include <string>
using namespace std;

class Person {
    string name_;
    int age_;
public:
    Person(const string& n, int a) : name_(n), age_(a) {}

    // const 成员函数：承诺不修改对象
    string getName() const { return name_; }
    int getAge() const { return age_; }

    // 非 const 成员函数：可能修改对象
    void birthday() { ++age_; }  // 修改了 age_
};

int main() {
    Person alice("Alice", 20);
    const Person bob("Bob", 25);  // const 对象

    // 非 const 对象可以调用所有函数
    cout << alice.getName() << " is " << alice.getAge() << endl;
    alice.birthday();
    cout << "After birthday: " << alice.getAge() << endl;

    // const 对象只能调用 const 成员函数
    cout << bob.getName() << " is " << bob.getAge() << endl;
    // bob.birthday();  // ❌ 编译错误！const 对象不能调用非 const 函数

    return 0;
}
```

> **规则**：`const` 对象只能调用 `const` 成员函数。把你**不修改对象**的成员函数都标记为 `const`——让别人放心用，也让编译器帮你检查。

## 五、内联函数

```cpp {cmd=true}
#include <iostream>
#include <cmath>
using namespace std;

class Point {
    double x, y;
public:
    Point(double a, double b) : x(a), y(b) {}

    // 定义在类内的函数默认是内联的
    double getX() const { return x; }  // 内联
    double getY() const { return y; }  // 内联

    // 类外定义，但用 inline 关键字
    double distance() const;
};

inline double Point::distance() const {
    // inline: 编译器将函数体直接替换到调用处，避免函数调用开销
    return sqrt(x * x + y * y);
}

int main() {
    Point p(3, 4);
    cout << "Point(" << p.getX() << ", " << p.getY() << ")" << endl;
    cout << "Distance from origin: " << p.distance() << endl;
    return 0;
}
```

> 短小、频繁调用的函数适合内联。长函数内联会导致代码膨胀。

## 六、完整示例：学生成绩管理系统

将前面学到的知识整合：封装、构造函数、const 成员函数、访问器。

```cpp {cmd=true}
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
#include <iomanip>
#include <sstream>
#include <stdexcept>
using namespace std;

class Student_info {
public:
    // 构造函数
    Student_info() : midterm(0), final(0) {}
    Student_info(istream& is) { read(is); }

    // 成员函数
    istream& read(istream& in) {
        in >> n >> midterm >> final;
        homework.clear();
        double x;
        while (in >> x) homework.push_back(x);
        in.clear();
        return in;
    }

    double grade() const {
        if (homework.empty())
            throw domain_error("student has done no homework");
        double sum = 0;
        for (double h : homework) sum += h;
        return 0.2 * midterm + 0.4 * final
             + 0.4 * sum / homework.size();
    }

    // 访问器
    string name() const { return n; }
    bool valid() const { return !homework.empty(); }

private:
    string n;
    double midterm, final;
    vector<double> homework;
};

// 非成员函数
bool compare(const Student_info& x, const Student_info& y) {
    return x.name() < y.name();
}

int main() {
    vector<Student_info> students;

    // 用预置数据模拟输入
    struct { const char* data; } inputs[] = {
        {"Alice   85 90 95 88 92 90 87"},
        {"Bob     72 78 80 85 82"},
        {"Charlie 90 95 100 98 92 96"},
        {"Diana   58 62 55 60"},
    };

    for (auto& in : inputs) {
        Student_info s;
        istringstream iss(in.data);
        if (s.read(iss))  // 读取成功
            students.push_back(s);
    }

    // 排序
    sort(students.begin(), students.end(), compare);

    // 打印成绩单
    cout << "=== 学生成绩管理系统 ===" << endl;
    cout << left << setw(12) << "姓名" << "成绩" << endl;
    cout << string(20, '-') << endl;

    for (const auto& s : students) {
        cout << left << setw(12) << s.name();
        try {
            cout << fixed << setprecision(1) << s.grade();
        } catch (const domain_error& e) {
            cout << "N/A";
        }
        cout << endl;
    }

    return 0;
}
```

## 七、第五周总结

| 知识点 | 说明 | C 语言中 |
|---|---|---|
| `class` vs `struct` | `class` 默认 private，`struct` 默认 public | `struct` 只有公开数据 |
| `public:` | 公共接口，所有人可访问 | （不存在） |
| `private:` | 私有实现，仅类内可访问 | （不存在） |
| 构造函数 | 创建对象时自动调用的初始化函数 | 手动写 `init()` 函数 |
| 初始化列表 | 在构造函数体执行前初始化成员 | 不存在，只能在函数体内赋值 |
| `const` 成员函数 | 承诺不修改对象状态 | （不存在） |
| `inline` | 函数体直接替换到调用处 | `#define` 宏（但不安全） |
| 访问器函数 | 以只读方式暴露内部数据 | 直接读成员 |

### 成员函数归属判断口诀

```
要修改对象状态？   → 成员函数
不修改、操作对称？ → 非成员函数（如 compare, operator+）
只读访问隐藏数据？ → 访问器成员函数（const）
```

> **课后练习**：将你的 `Student_info` 从 `struct` 改写为 `class`，添加构造函数、私有数据成员和公共访问器函数。确保 extern 函数 `compare` 仍然能正常工作。
